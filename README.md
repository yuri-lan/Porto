# Portofolio Hayulita

Website portofolio pribadi sederhana yang dibuat untuk memenuhi tugas praktikum Pemrograman Web. Website ini menampilkan profil singkat, keahlian yang sedang dipelajari, proyek, serta informasi kontak.

Website ini telah dipublikasikan secara publik menggunakan GitHub Pages.

## Fitur Website

- Desain antarmuka dengan tema warna maroon dan cream yang elegan.
- Responsif dan optimal jika diakses melalui komputer maupun ponsel.
- Dilengkapi dengan fitur pengubah tema (mode terang dan mode gelap).
- Animasi interaktif seperti efek ketik (typing effect), elemen mengambang, dan animasi muncul saat halaman digulir (scroll reveal).
- Menu navigasi khusus untuk tampilan ponsel (hamburger menu).

## Teknologi yang Digunakan

- HTML5 untuk struktur halaman.
- CSS3 untuk tata letak, warna, dan animasi.
- JavaScript untuk logika interaktif (tema, animasi, dan menu).
- Google Fonts (Playfair Display dan Plus Jakarta Sans).

## Struktur Folder

- `index.html` : File utama yang berisi struktur website.
- `style.css` : File yang mengatur seluruh tampilan dan desain.
- `script.js` : File yang berisi logika interaksi dan animasi.
- `README.md` : File dokumentasi proyek ini.
